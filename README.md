# Numerical Methods & Computational Mathematics (`Calculation-methods`)

This repository contains a curated collection of Jupyter Notebooks dedicated to the implementation and analysis of core numerical methods, scientific computing, and applied linear algebra in **Python**.

---

## 📌 Repository Overview

The primary goal of this repository is to demonstrate the underlying mechanics, accuracy, convergence rates, and algorithmic logic of standard computational mathematics techniques. Rather than relying solely on high-level library abstractions, these notebooks emphasize step-by-step mathematical implementations.

---

## 🔑 Key Thematic Modules & Methodology

---

### 1. 📐 Computational Linear Algebra
* **Direct Solvers for SLAE:** Gaussian elimination (with partial pivoting), LU Decomposition ($A = L \cdot U$), and Cholesky factorization.
* **Iterative Solvers:** Jacobi method, Gauss-Seidel method, and Successive Over-Relaxation (SOR) for system resolution.
* **Matrix Analytics:** Matrix inversion, determinants, and condition number analysis.

---

### 2. 📉 Non-linear Equations & Root-Finding Algorithms
* **Single-Variable Equations:** Bisection method, Secant method, False Position (Regula Falsi), and Newton-Raphson iterations.
* **Systems of Non-linear Equations:** Multivariable Newton-Raphson and fixed-point iteration strategies.

---

### 3. 📊 Interpolation & Function Approximation
* **Polynomial Interpolation:** Lagrange polynomials, Newton's divided differences, and polynomial evaluation.
* **Spline Fitting:** Cubic spline construction for smooth data approximation.
* **Least Squares Method (LSM):** Linear and polynomial curve fitting for statistical data modeling.

---

### 4. ♾️ Numerical Integration & Differentiation
* **Quadrature Rules:** Rectangle rules (midpoint, left, right), Trapezoidal rule, and Simpson's $1/3$ & $3/8$ rules.
* **Error Estimation:** Runge's principle for error estimation and adaptive step-size control.

---

# Чисельні методи та прикладна математика (`Calculation-methods`)

Даний репозиторій містить серію дослідницьких Jupyter Notebooks, присвячених реалізації фундаментальних методів обчислювальної математики, чисельного аналізу та розв'язання задач лінійної алгебри мовою **Python**.

## 📌 Загальний огляд репозиторію

Основна мета репозиторію — практична реалізація та аналіз алгоритмів чисельних методів: від обчислення систем лінійних алгебраїчних рівнянь (СЛАР) до інтегрування, апроксимації та інтерполяції функцій. 

Проєкт орієнтований на дослідження точності, збіжності та обчислювальної складності стандартних математичних алгоритмів без використання лише «чорних скриньок» сторонніх бібліотек, а шляхом безпосередньої програмування алгоритмів.

## 🔑 Ключові тематичні блоки та методологія

---

### 1. 📐 Лінійна алгебра та системні обчислення
* **Прямі методи розв'язання СЛАР:** Метод Гаусса (з вибором головного елемента), LU-розклад матриць ($A = L \cdot U$), розклад Холецького ($LL^T$).
* **Ітераційні методи:** Метод простої ітерації, метод Якобі та метод Зейделя для розв'язання великих або розріджених систем рівнянь.
* **Матричні операції:** Знаходження оберненої матриці, обчислення визначників та дослідження обумовленості матриць.

---

### 2. 📉 Чисельне розв'язання нелінійних рівнянь та систем
* **Локалізація та уточнення коренів:** Метод половинного ділення (бісекції), метод хорд, метод дотичних (Ньютона-Рафсона) та метод січних.
* **Системи нелінійних рівнянь:** Багатовимірний метод Ньютона та метод модифікованих ітерацій.

---

### 3. 📊 Інтерполяція, апроксимація та наближення функцій
* **Поліноміальна інтерполяція:** Інтерполяційні многочлени Лагранжа та Ньютона (з розділеними та скінченними різницями).
* **Сплайн-інтерполяція:** Побудова кубічних сплайнів для згладжування даних.
* **Метод найменших квадратів (МНК):** Лінійна та поліноміальна регресія для апроксимації експериментальних даних.

---

### 4. ♾️ Чисельне інтегрування та диференціювання
* **Квадратурні формули:** Формули лівих/правих/середніх прямокутників, трапецій та метод Сімпсона (парабол).
* **Оцінка точності:** Використання правило Рунге для контролю похибки та автоматичного вибору кроку інтегрування.
